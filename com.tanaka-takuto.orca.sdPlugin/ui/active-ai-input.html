直近のキー操作

このプラグイン起動中の記録はありません。過去の未入力を示すものではありません。

既存の入力は消しません。Enter を送る場合は既存の入力も含めて送信します。入力先をキーで確認してから押してください。

現在は macOS / Linux のローカル AI ターミナルが対象です。ネイティブ Chat は対象外です。

端末位置の T は端末レイアウト内のタブ順です。ファイルやブラウザを含む全タブ番号ではありません。保存選択は現在の画面選択を保証しません。結果不明時は Orca で確認し、必要な場合だけキーを押し直してください。
