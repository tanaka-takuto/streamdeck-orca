ORCA / PR REVIEW

レビュー依頼からAI起動

回してPRを選び、押すと対象ブランチのワークスペースで新しいAIを起動します。ワークスペースがなければ作成します。

Orcaのデフォルトは押す時点のOrca設定を使います。未設定・通常ターミナル・無効なAIの場合は起動しません。

PRのURLは {{PR_LINK}}（{{pr_url}} も使用可）、番号は {{pr_number}}、リポジトリは {{repo}}、対象ブランチは {{branch}}、コミットは {{head_sha}}、比較先は {{base_branch}} で挿入できます。

オフの場合は下書きとして入力します。レビューの開始はOrcaでEnterを押したときです。

同じPRでAIを起動し直す

同じコミットで起動済みのPRは、押すとワークスペースを開きます。再度起動したい場合は、先にOrcaで前回のAIや入力状況を確認してください。

解除だけではAIは起動しません。次のダイヤル押下で新しいAIを起動します。

回す：PRを選択 ／ 押す：AI起動・入力 ／ 画面をタップ：一覧更新。設定は保存後に反映され、保存だけではAIを起動しません。

GitHub CLIへのログインが必要です。未登録のリポジトリは ~/orca/review-repositories/ に取得し、Orcaに追加します。作業中の変更や古いHEADがあるワークスペースは自動で書き換えません。
